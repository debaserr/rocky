# Rocky — Domain Glossary

## BWF Primer
The 6-exercise beginner bodyweight routine done 3 times per week: Deadbugs, Bird dog, Push-ups, Rows, Squats, Bridges. Each exercise has a progression list, a rep range, and a fixed rest time between sets.

## Exercise
One of the 6 movements in the BWF Primer. Each exercise has: a name, a link to its tutorial, a progression list, a rep range (min–max), and a rest time.

## Progression Level
An integer indicating which variant of an exercise the user is currently performing. Derived from the exercise's progression list (e.g. Push-up progression level 2 = a specific harder push-up variant).

## Set
A single round of reps within an exercise. Each exercise requires 3 sets per session.

## Rep
One repetition of an exercise movement. Each set has a target rep count.

## Rest Period
The timed pause between sets. Fixed per exercise: 60s (Deadbugs, Bird dog), 90s (Squats, Bridges), 2 min (Push-ups, Rows).

## Session
One complete workout — all 6 exercises performed in order, each with 3 sets.

## Progress
The user's current state for an exercise: their progression level and current target reps.

## Level Up
When the user completes the max reps for their progression level on all sets of an exercise, their progression level increments by 1 and their rep count resets to the range minimum for that exercise.
